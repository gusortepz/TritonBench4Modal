IMPLEMENTATION STRATEGY

Use this decision tree:

1. Simple elementwise or broadcasting op:
   - use exact PyTorch fallback by default;
   - use Triton only for simple unary tensor inputs with no dtype/broadcast/out surprises.

2. Simple row-wise reduction or normalization:
   - use PyTorch fallback unless the axis semantics are explicit and simple.

3. Matrix multiply / BMM:
   - use torch.matmul or torch.bmm fallback.

4. Convolution, pooling, batch norm, layer norm, group norm, RMS norm, dropout, embedding, gather/scatter:
   - use torch.nn.functional or torch fallback.

5. Linear algebra decompositions, solvers, eigen, SVD, QR, LU, Cholesky, least squares, FFT:
   - use PyTorch fallback.
   - Do not attempt full Triton implementations.

6. Special functions: gammaln, digamma, polygamma, bessel_j*, airy_ai, zeta, i0, erfc, chebyshev_polynomial_t:

   - otherwise use a PyTorch reference implementation.

7. Stochastic ops, optimizers, autocast, quantize_dynamic:
   - use PyTorch implementation. Respect training, p, and seed behavior where possible.

8. In-place PyTorch-style ops (functions ending in _):
