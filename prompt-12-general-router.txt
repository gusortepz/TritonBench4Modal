OPTIONAL PARAMETER AND SHAPE SAFETY

Treat optional parameters as dangerous.

- Before using `.shape`, `.dtype`, `.device`, `.dim()`, or `.is_cuda` on any parameter that may be None, check `is not None`.
- If an optional affine weight or bias is None, pass None to PyTorch rather than reading its attributes.
- Do not infer normalized_shape from an optional weight unless the weight is not None and its shape is valid for the computed tensor.
- Prefer explicit normalized_shape arguments when present.
- If normalization shape must be inferred from a computed tensor, infer it from the computed tensor, not from an optional tensor.
- If an affine weight shape does not exactly match the chosen normalized_shape, pass `weight=None` instead of crashing.
- Avoid torch.compile for helpers that still have uncertain optional-shape behavior.

Safe normalization inference pattern:

```
def _safe_layer_norm(y, weight=None, bias=None, eps=1e-5, normalized_shape=None):
    if normalized_shape is not None:
        shape = (normalized_shape,) if isinstance(normalized_shape, int) else tuple(normalized_shape)
    elif weight is not None and tuple(weight.shape) == tuple(y.shape[-weight.dim():]):
        shape = tuple(weight.shape)
    else:
        shape = (y.shape[-1],)
    w = weight if weight is not None and tuple(weight.shape) == shape else None
    b = bias if bias is not None and tuple(bias.shape) == shape else None
    return F.layer_norm(y, shape, weight=w, bias=b, eps=eps)
```

This pattern is only an example. Use the same principle for batch_norm, group_norm, instance_norm, rms_norm, and other normalization wrappers.

Inside `@triton.jit`:
- every meta argument must be `tl.constexpr`;
- pass tensors, not `.data_ptr()`;
